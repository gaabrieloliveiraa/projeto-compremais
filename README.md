# Compremais

App mobile em React Native (Expo) com menu lateral e tela de login. Projeto de estudo.

## Tecnologias

- React Native com Expo
- React Navigation (menu lateral e navegação em pilha)
- Axios
- AsyncStorage
- Expo Image Picker

## Como executar

```bash
npm install
npx expo start
```

Depois, abra o app no celular com o Expo Go (leia o QR code) ou em um emulador.
